# Diario Dieta (web)

Diario alimentare per seguire il piano del nutrizionista: pasti, calorie e macro, acqua, peso e BMI, misure, lista della spesa, allenamenti.

I dati restano nel browser di chi usa l'app: questo repository contiene solo il codice. Per caricare i propri dati: Profilo → Ripristina da backup.
